**Goal:** Deliver a host-independent, fail-closed UID502 preflight *schema/consistency contract* and adversarial tests without granting real host or CI execution authority.

## File Map and Interfaces

| File | Single responsibility |
| --- | --- |
| `ops/live-e2e/uid502_preflight_contract.py` (new) | Frozen evidence data classes, fixed literals, pure validators and non-authoritative aggregate result |
| `tests/ops/test_uid502_preflight_contract.py` (new) | Import actual source via `importlib.util.spec_from_file_location` with temporary `sys.modules` registration for `dataclasses`; synthetic hostile-evidence tests and zero-I/O guard |

| `docs/evidence/2026-10-14-adr19-uid502-preflight-contract.md` (new) | Feature evidence template, source SHA/test results, explicit unverified real UID502 state, no false release PASS |

**Locked public API** (types defined as `@dataclass(frozen=True, slots=True)`; all collection properties immutable `tuple`, no `dict`-typed mutable field):

- `RunIdentity(repository: str, event: str, ref: str, github_sha: str, inputs: tuple[tuple[str,str], ...])`.
- `CheckoutEvidence(head_sha: str, clean: bool, checkout_uses: str, checkout_ref: str, persist_credentials: bool, checkout_clean: bool, fetch_depth: int, credential_env_present: bool, credential_helper_present: bool, complete: bool)`.
- `WorkflowJobEvidence(permissions: tuple[tuple[str,str], ...], runs_on: tuple[str,...], concurrency_group: str, cancel_in_progress: bool, complete: bool)`; exact permissions `(("contents","read"),)`, exact **ordered** labels, shared concurrency and cancellation.
- `RunnerIdentity(user: str, home: str, uid: int, euid: int, account_uid: int, gid: int, egid: int, account_primary_gid: int, supplementary_gids: tuple[int,...], admin_gid: int, group_names: tuple[str,...], platform: str, arch: str, complete: bool)`. Numeric IDs use `type(x) is int`, nonnegative; supplementary IDs sorted and unique; admin GID exactly 80 and absent from every real/effective/account-primary/supplementary GID. `group_names` is purely informational (benign string names cannot override numeric checks). Do not require real/effective/account-primary GID equality that the existing `protected_staging._validate_context()` does not require.
- `PathWitness(name: str, dev: int, ino: int, uid: int, gid: int, mode: int, acl_state: str, kind: str, target: str | None, writable_by_uid502: bool)`. `name` is an exact literal fixed component, never a user-chosen base path.
- `InterpreterInventory(resolved_path: str, sys_executable: str, version: tuple[int,int,int], arch: str, complete: bool, chain: tuple[PathWitness,...])`.
- `InterpreterTrustPolicy(policy_label: str, expected_path: str, version: tuple[int,int,int], allowed_owner_uid: int, allowed_owner_gid: int, approved_chain: tuple[str,...])`. `policy_label="TEST_ONLY_NOT_AUTHORITY"` represents a fictional **synthetic** root-owned 0:0 `/test-only/uid502-pinned/python3.13` path with no group/world write, not an approval. Real observed mixed-owner/group-writable Homebrew path must refuse. Code-signing, binary digest and signer provenance are outside this API and **UNVERIFIED**, to be designed/reviewed with any future host collector.
- `NamespaceEdge(name: str, original: tuple[int,int,int,int,int], current: tuple[int,int,int,int,int], acl_state: str, nofollow: bool)` (identity tuple is dev/ino/uid/gid/full mode).
- `NamespaceEvidence(verification_root: str, protected_root: str, native_temp_parent: str, edges: tuple[NamespaceEdge,...], complete: bool, foreign_entry: bool, quarantine_present: bool, alias_disjoint: bool)`.
- `ProviderInventory(marker_state: str, marker_chain_pinned: bool, qemu_state: str, qemu_count: int | None, protected_clean: bool, legacy_private_clean: bool, legacy_native_clean: bool, complete: bool)`.
- `ContractEvidence(run: RunIdentity, checkout: CheckoutEvidence, job: WorkflowJobEvidence, runner: RunnerIdentity, interpreter: InterpreterInventory, namespace: NamespaceEvidence, provider: ProviderInventory)`.
- `ContractResult(status: str, violations: tuple[str,...])`, where `status` is exactly one of `CONTRACT_REFUSED` or `CONTRACT_ELIGIBLE_FOR_HOST_PROBE`.
- Pure interfaces: `validate_run(run: RunIdentity, checkout: CheckoutEvidence, job: WorkflowJobEvidence, runner: RunnerIdentity) -> tuple[str,...]`; `validate_interpreter(inventory: InterpreterInventory, policy: InterpreterTrustPolicy | None) -> tuple[str,...]`; `validate_namespace(namespace: NamespaceEvidence) -> tuple[str,...]`; `validate_provider(provider: ProviderInventory) -> tuple[str,...]`; `assess(evidence: ContractEvidence, *, interpreter_policy: InterpreterTrustPolicy | None = None) -> ContractResult`.

All validation functions return finite fixed code literals; `assess` sorts and deduplicates them and refuses malformed evidence with `EVIDENCE_INVALID`. The caller-controlled `policy_label` is **not** trusted signing evidence, operator approval or authorization.
