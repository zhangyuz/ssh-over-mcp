## Official source-linked behaviors (not observations of this artifact)

| Published tool/security behavior | Official / manual reference | What evidence it **does not** establish |
| --- | --- | --- |
| Apple recommends `pkgutil --check-signature` to debug signed installer packages; valid Developer ID Installer checks surface a certificate chain and secure timestamp | [Apple: common notarization issues](https://developer.apple.com/documentation/security/resolving-common-notarization-issues) | Does **not** prove the package's approved team/leaf role, cert trust at the policy's historical signing time, revocation freshness or absence of malicious install scripts |
| Apple's notary service accepts **flat installer packages** and issues a ticket that can be **stapled** to the distributed package or found online by Gatekeeper | [Apple: notarization](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution) | Notarization is automated malware/code-signing assessment, **not App Review**; a ticket is not a safe-effects inventory and does not override separate Apple Installer CMS/signature checks |
| Apple documents ticket **stapling** for offline Gatekeeper access; `stapler staple` **changes** its input, whereas inspection-only validation must be separately evaluated and proven non-mutating under a reviewed runbook | [Apple: notarization workflow](https://developer.apple.com/documentation/security/customizing-the-notarization-workflow) | Ticket presence/validation alone cannot prove signed source, trust-anchor authenticity, all installed effects, or that an offline check had fresh revocation evidence. **Never staple the canonical B0a/B0b input during proof** |
| `pkgutil --payload-files` lists files in uninstalled flat packages, but the man page warns the actual **destination location is unknown** to the command. `pkgutil --bom` materializes BOM(s) in **/tmp**, and `--expand`/`--expand-full` write extracted files into output directories | [macOS pkgutil manual](https://keith.github.io/xcode-man-pages/pkgutil.1.html) | A payload listing is **not** a complete install-effects, script, symlink/ACL or write-target inventory. Commands that write scratch must **not** run on the unapproved persistent host or outside an isolated, quota-bound, audited temp root |
| Apple certificate trust, Gatekeeper `spctl` verdict and notarization ticket are distinct inputs to a source decision; multiple checks can disagree on particular OS builds | [Apple notarization](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution), [Apple developer forum case (anecdotal, not normative)](https://developer.apple.com/forums/thread/817887) | A single `spctl`, `stapler`, `pkgutil` exit code or claim `notarized=true` cannot silently grant trust or override a conflicting observation; OS-build-specific discrepancies **REFUSE / escalate** |

## Independent B0b receipt obligations — no execution in this slice

| Gate | Future separately approved evidence | Negative / refusal examples |
| --- | --- | --- |
| **B0a→B0b custody (T6)** | Before *any* PKG parser or trust tool, independently prove exclusive writer exclusion and an immutable inspection view; independently remeasure **every byte + exact length**, compare the **full SHA-256, canonical release/name, approved policy digest/revision** to authenticated B0a evidence and independently approved expected values; record authenticated transfer receipts and OS/tool provenance | Same basename/length but different bytes; symlink/alias/drift; swapped/replayed receipts; changed policy revision; mutable inspection copy → `B0_UNVERIFIED` |
| **Apple Installer CMS (T7)** | On a separately trusted **isolated macOS host**, pin Apple Developer ID **Installer** cert type, independently approved expected team/leaf, signed chain/purpose/time, revocation and offline root policy; tie any tool output to exact immutable inspected bytes, OS build and tool closure | Wrong signer team, Developer ID Application instead of Installer, expired/revoked/ambiguous chain, unknown time/root or tool tampering → `B0_UNVERIFIED` |
| **Notarization (T7)** | Record verifiable ticket origin, matching artifact identity, signed time/expiry and offline revocation disposition under explicitly approved policy, without mutating the original PKG or requesting a remote service during no-network inspection | Missing ticket when policy requires offline proof; invalid/mismatched/stale ticket; online-only lookup or contradictory `spctl`/`stapler`/CMS observations → `B0_UNVERIFIED` |
| **Installer operations inventory (T8)** | Bound and enumerate **every** nested component, Distribution/choices (including JavaScript), `PackageInfo`, BOM, cpio/payload, resources, pre/postinstall scripts, symlink/hardlink targets, global paths, LaunchServices/launchd hooks, receipts and condition-dependent effects, without running script code | Unknown nested structure, dynamic script/network behavior, unallowlisted global PATH writes, outside-root traversal, decompression bombs or incomplete inventory → `B0_UNVERIFIED` |
| **Reviewable source decision (T9)** | Immutable bounded signed audit tying Mac-host identity, parsed tool returns, exact SHA/size/policy/custody and independently reviewed effects allowlist to **separate operator approval** | `source_verified=true` from any individual CLI, bundle, installer filename, source web page, unsigned log or synthetic fixture → **NO SOURCE AUTHORITY** |

## Proposed later adversarial acceptance — not run, not execution authorization

- **Custody RED:** same-name/same-length different package bytes, substituted B0a record, drift during B0b processing, stale B0b policy, modified witness or ownership -> no evidence promotion.
- **Signer/time RED:** wrong Apple Developer ID category/team/leaf, expired/unknown leaf or chain, unpinned root, missing trusted timestamp/revocation witness; a Sigstore B0a positive cannot rescue B0b.
- **Effects RED:** malicious BOM traversal, duplicate conflict, nested installer with an extra script, writable global PATH/symlink, unexpected LaunchDaemon, conditional Distribution choice, compression bomb and parser timeout.
- **Tool isolation:** prove independently approved macOS build/toolchain/root provenance and network-disabled, credential-free isolation before any future command; `pkgutil --bom` writes scratch, `--expand-full` extracts hostile bytes, and `stapler staple` modifies its target. Do not run `installer`, `sudo`, scripts, payload executables, `spctl --master-disable`, quarantine-removal or online notary submission.
- **Positive synthetic parser fixtures** may demonstrate only bounded complete inspection and secure refusal behaviors; **cannot mint** genuine Apple Developer ID identity, notarization, or source approval without separately authorized genuine signed input.
- **B0b outcome:** even independently supported B0a+B0b evidence remains `B0_UNVERIFIED` until the distinct explicit **operator source-decision join**; B1 provisioning/B2 at-use/B3 UID502/APFS nine-case/B4 staging/release remain separate gates.
